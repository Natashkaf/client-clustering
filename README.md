# Кластеризация клиентов по картовым транзакциям

Учебный проект по анализу данных на Python: сегментация клиентов на основе поведения в транзакциях по банковским картам.

## Цель
Разделить клиентов на группы со схожим поведением при оплате картой и описать, чем эти группы отличаются.

## Что сделано
- **Загрузка данных:** транзакции читаются из parquet-файлов с помощью Dask.
- **Построение признаков на уровне клиента:**
  - сумма операций: средняя, общая и количество транзакций;
  - доля e-commerce операций, доля операций с признаком дохода, доля операций в выходные;
  - среднее значение `hour_diff`;
  - число уникальных валют, типов операций, типов карт, групп операций, платёжных систем, MCC-кодов, стран, городов и недель активности;
  - среднее число транзакций в неделю.
- **Подготовка к кластеризации:** стандартизация признаков (`StandardScaler`).
- **Кластеризация:** алгоритм K-Means (`k-means++`), 5 кластеров.
- **Анализ кластеров:** размеры кластеров, гистограммы и KDE-графики распределения каждого признака по кластерам (на выборке из 50 000 клиентов), средние значения признаков по кластерам.

## Стек
Python, Dask, pandas, scikit-learn, seaborn, matplotlib, NumPy
